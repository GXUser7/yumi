# Mock Billing Server (OSB v0.1)

Локальный тестовый сервер для проверки Open Subscription Billing (`billing-manifest-url`, `payment-url`, `POST /checkout`, возврат через `mydrop://billing/return`) в debug-сборках Yumi VPN без внешнего интернета и реальных платёжных шлюзов.

## Запуск на ПК

```bash
python tools/mock-billing-server/server.py --host 127.0.0.1 --port 8787
```

## Подключение с телефона через ADB

В debug-сборке (`BuildConfig.DEBUG`) Yumi разрешает HTTP только для `127.0.0.1`, `localhost`, `[::1]` и `10.0.2.2`. Чтобы открыть локальный сервер прямо на телефоне по кабелю:

```bash
adb reverse tcp:8787 tcp:8787
```

После этого добавьте в Yumi (или передайте через deep link) подписку:

- Обычная активная подписка: `http://127.0.0.1:8787/sub/demo`
- Скоро истекает (`<= 2 дн.`): `http://127.0.0.1:8787/sub/demo?mode=urgent`
- Истёкшая подписка (`0.0.0.0:1`): `http://127.0.0.1:8787/sub/demo?mode=expired`
- Лимит устройств (`x-hwid-max-devices-reached`): `http://127.0.0.1:8787/sub/demo?mode=hwid`

На Android-эмуляторе вместо `127.0.0.1` используйте `http://10.0.2.2:8787/sub/demo`.

## Сценарий проверки

1. Импортируйте `http://127.0.0.1:8787/sub/demo` в Yumi и откройте экран **Подписки**.
2. Нажмите **Тарифы** (или **Продлить**) на карточке `Test`.
3. В листе тарифов выберите план (например, `3 месяца Pro`), при необходимости введите промокод `YUMI10` (скидка 10%) и выберите способ оплаты.
4. Нажмите кнопку оплаты — откроется страница `http://127.0.0.1:8787/pay/<order_id>`.
5. Нажмите **Оплатить и вернуться в Yumi** — сервер продлит состояние `demo` и перенаправит на `mydrop://billing/return?sub_id=...&order_id=...`, после чего приложение автоматически обновит подписку.
6. Чтобы сбросить состояние `demo` в исходное, вызовите `http://127.0.0.1:8787/sub/demo?reset=1` или `POST /api/billing/demo/reset`.
