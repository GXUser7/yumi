# Yumi

VPN-клиент для Android: подписки, серверы по ссылке или QR-коду, туннель на ядре
[sing-box](https://github.com/SagerNet/sing-box) и интерфейс на Material 3 Expressive.

**[Скачать последнюю версию](https://github.com/GXUser7/yumi/releases/latest)** ·
[Канал в Telegram](https://t.me/MaterialYouCloud)

Почти всем нужен файл **arm64-v8a**. Сборка `armeabi-v7a` — только для очень старых телефонов;
если не уверены, какой у вас, берите arm64. Нужен Android 8.0 или новее.

## Что умеет

**Серверы.** Ссылки `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` и `tuic://` —
вставкой из буфера, сканированием QR-кода или прямо по нажатию на ссылку в другом приложении.
Подписки обновляются одной кнопкой и показывают остаток трафика и срок, если сервер их сообщает.

**Задержка.** Замер по каждому серверу тремя способами: рукопожатие TCP, полное рукопожатие TLS
(для REALITY это разница между «порт открыт» и «маскировка работает») и медиана из трёх проб.
Узлы на QUIC — Hysteria2 и TUIC — проверяются отдельной UDP-пробой. Список сортируется по
задержке, есть выбор самого быстрого.

**Скорость.** Замер приёма, отдачи, отклика и разброса **через выбранный сервер**, а не мимо
туннеля — то есть меряется VPN, а не канал телефона. Со стрелочным прибором и живым графиком.
Пока в бете: числа ещё уточняются.

**Маршрутизация.** Три режима: всё через туннель, всё напрямую и по правилам — российские сайты
и адреса идут мимо VPN. Гео-правила лежат внутри приложения, поэтому подключение не ждёт загрузки
списков из сети. Отдельно: обход локальной сети и блокировка рекламных доменов.

**Раздельное туннелирование.** Список приложений, которые ходят только через VPN, — или наоборот,
только мимо него.

**Уход с упавшего сервера.** Приложение следит за сервером, на котором стоит туннель, и
переезжает на живой из той же подписки, когда тот перестаёт отвечать. Смена сервера на включённом
VPN не разрывает туннель: ядро переключается на месте.

**Ещё.** Плитка в шторке, автозапуск при загрузке телефона, поддержка «Постоянного VPN» в
настройках Android, журнал ядра прямо в приложении, тёмная тема с AMOLED-режимом и палитра из
обоев системы.

## Приватность

Приложение не собирает статистику и никуда не отправляет данные о вас. Серверы, подписки и ключи
лежат только на телефоне. Единственные соединения, которые оно делает само, — обновление ваших
подписок, замер задержки до ваших серверов и, если вы его запустите, замер скорости
(`speed.cloudflare.com`).

## Установка

1. Скачайте `yumi-<версия>-arm64-v8a.apk` из [релизов](https://github.com/GXUser7/yumi/releases/latest).
2. Откройте файл и разрешите установку из этого источника, если Android спросит.
3. При первом подключении система спросит разрешение на VPN — без него туннель не поднять.

Обновления ставятся поверх, серверы и настройки сохраняются.
